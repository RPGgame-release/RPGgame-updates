# RPGgame-updates

**勇ましき者の冒険（仮）** の、更新ファイルの置き場所です。

ゲーム（exe版）が、起動したときに、ここの最新のリリースを、自動で、確認します。
ふつうに遊ぶ人は、ここから、何かを、ダウンロードする必要は、ありません。

## 中身

リリースごとに、次の2つを置いています。

- `update.json` … 新しい版の番号と、ファイルの照合用の情報
- `game-版.zip` … ゲームのコードと画像（更新用）

## ご注意

- ゲームに同梱の素材画像（dot-illust.net）を、第三者へ、再配布・販売することは、禁止です。
- 制作にはAIを使用しています。ご注意ください。
